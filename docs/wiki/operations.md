# Эксплуатация и границы demo

## Локальный demo

```text
docker compose up --build
```

После запуска приложение доступно на `http://localhost:8000`. Compose создаёт
SQLite-базу и синтетические записи через `seed_portfolio_demo`; реальные данные,
документы и ключи для просмотра не требуются.

## Наблюдаемость и обслуживание

Приложение предоставляет health endpoints: `/healthz/`, `/health/` и
`/readyz/`. Системный раздел включает запуск backup/restore и контроль их
состояния; scheduler выполняет регламентные операции.

Для production-like среды нужны MariaDB, отдельный пользователь БД, приватные
постоянные каталоги для документов и резервных копий, HTTPS и проверенный
reverse proxy. Восстановление следует сначала выполнять в изолированном
окружении, подтверждая целостность БД и файлов.

## Статус

Это MVP / pre-production система. Локальные и e2e-проверки пройдены, однако
целевые acceptance-проверки окружения и объёмного импорта не заявляются как
завершённые в публичной витрине.
