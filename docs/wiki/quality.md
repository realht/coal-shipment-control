# Качество и проверка

Код проверяется на нескольких уровнях: модульные и интеграционные Django-тесты,
статический анализ, проверка актуальности CSS и критические e2e-сценарии.

```text
python -m pytest app
python -m ruff check app
npm ci
npm run check:css
```

GitHub Actions запускает Django-тесты, Ruff и CSS drift check для каждого
изменения. В public showcase последняя полная локальная проверка завершилась
успешно: 1002 теста прошли. Это число относится именно к очищенной публичной
копии; приватный исходный проект содержит дополнительные проверки внутренних
материалов и deployment-сценариев.

Критические пользовательские потоки дополнительно покрыты Playwright. Docker и
MariaDB acceptance не запускаются в публичном CI, потому что им нужно отдельное
production-like окружение; они остаются обязательной ручной проверкой перед
целевым развёртыванием.
