# Безопасность и контроль доступа

Система рассчитана на внутренний доступ нескольких сотрудников, поэтому
контроль прав и прослеживаемость операций встроены в прикладной слой.

## Меры в приложении

- RBAC реализован через Django permissions: права проверяются до открытия
  чувствительных экранов и выполнения изменяющих операций;
- доступ к загруженным документам проходит через приложение, а не через
  публичную раздачу каталога с файлами;
- при загрузке проверяются разрешённые расширения, размер и MIME-содержимое;
- импорт XLSX выполняется с предварительным просмотром, валидацией строк и
  диагностикой дублей до подтверждения записи;
- экспорт нейтрализует формульно-подобные значения, чтобы снизить риск
  spreadsheet formula injection;
- аудит фиксирует операции с бизнес-сущностями; пароли и другие секреты в нём
  не сохраняются;
- секреты и параметры окружения передаются через `.env` вне репозитория, а в
  репозитории остаётся только безопасный `.env.example`.

Безопасность не заменяет организационные меры: production-like развёртывание
требует HTTPS, приватного хранилища, отдельных учётных данных БД и регулярной
проверки резервного восстановления.
