# Подготовка production-like окружения

Эта страница описывает требования к окружению, а не готовую инструкцию для
конкретной инфраструктуры.

- используйте MariaDB с отдельным непривилегированным пользователем приложения;
- передавайте `SECRET_KEY`, параметры БД и другие секреты через защищённое
  хранилище конфигурации, а не Git;
- разместите документы и резервные копии в приватных persistent-каталогах вне
  исходного кода;
- завершайте TLS на проверенном reverse proxy и настройте доверенные proxy
  headers только для известных прокси;
- перед вводом версии в эксплуатацию выполните миграции, инициализацию ролей и
  проверку ключевых сценариев доступа;
- фиксируйте версию сборки и результаты acceptance-проверок рядом с релизом.

Публичный Docker compose предназначен только для демонстрации и не заменяет эту
подготовку.
