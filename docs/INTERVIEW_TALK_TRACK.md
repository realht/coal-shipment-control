# Как рассказывать о проекте на собеседовании

1. **Проблема.** Общий Excel-файл не даёт безопасной одновременной работы,
   разграничения доступа и истории изменений.
2. **Решение.** Я спроектировал Django-систему для авто- и ЖД-отгрузок с RBAC,
   импортом/экспортом XLSX, документами и аудитом.
3. **Технический риск.** Наиболее чувствительные места — импорт внешних файлов,
   доступ к документам и восстановление данных. Поэтому добавлены ограничения
   размера, проверка MIME/XML, объектные права и проверяемые backup manifests.
4. **Проверка.** Использовал pytest, Playwright critical-flow тесты, Ruff,
   CSS drift check и release gate; Claude Code и OpenAI Codex ускоряли цикл, но
   финальные решения и верификация оставались за мной.
5. **Следующий этап.** Провести version-bound acceptance в целевой среде и
   нагрузочный импорт на production-like наборе данных.
