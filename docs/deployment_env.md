# Параметры окружения

Конкретные значения конфигурации не хранятся в репозитории. Для public demo
достаточно значений из `.env.example`; production-like среда должна задавать
свои секреты и параметры БД через защищённый механизм конфигурации.

Минимальные требования:

- уникальный `SECRET_KEY` достаточной длины;
- отдельные параметры подключения к MariaDB;
- лимиты HTTP-запроса и фильтров, согласованные с reverse proxy;
- persistent-каталоги для документов и резервных копий вне исходного дерева.
